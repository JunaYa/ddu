# Roadmap — React monorepo 迁移

面向：项目负责人。按**可见成果**组织；工程上的依赖顺序见 [91-impl-plan](./91-impl-plan.md)。

## 0. 原则

- **始终可发布。** 每个里程碑结束时 `vp run ready` 全绿、`.app` 可打包、用户可见行为不变（视觉风格趋同于设计系统除外）。
- **以窗口为单位。** 一个窗口要么全是 Vue，要么全是 React；每个里程碑可独立回滚。
- **先契约后页面。** 原生契约（[11](./11-native-bridge.md)）在第一个 React 窗口之前落地，后续窗口只做增量登记。
- **如实估算。** 估算按 1 名开发者 + AI 助手计，含人工核对与修复时间。

## 1. 构建顺序

```text
00-prd → 10-workspace → 11-native-bridge → 12-desktop-shell → 13-design-system
   M0：10                M1：11、12、13 + 设置窗口       M2–M5：逐个窗口       M6：清理
```

## 2. 里程碑

### M0 — 仓库变为 Vite+ monorepo（应用全部仍是 Vue）

用户无感知。开发者可以用 `vp` 完成安装、检查、测试、打包。

- **涉及规格**：[10](./10-workspace-layout.md)
- **退出标准**：
  - `vp install && vp run ready` 在干净克隆上全绿；
  - `vp run desktop#build:native` 产出可用的 `Ddu.app`，PDFium 位于 `Contents/Frameworks`；
  - 升级安装后屏幕录制授权仍有效（identifier 未变）；
  - CI 在 macOS runner 上通过。
- **估算**：1.5–2 天

### M1 — 设置窗口使用 React 与设计系统（本轮）

用户打开设置，看到设计系统风格的界面，功能与之前完全一致。开发者有了类型化的原生入口和窗口外壳，后续窗口照此迁移。

- **涉及规格**：[11](./11-native-bridge.md)、[12](./12-desktop-shell.md)、[13](./13-design-system.md)
- **退出标准**：
  - `src/legacy/pages/setting/` 已删除；
  - 设置窗口的六个分区通过人工核对清单（[12 § 6](./12-desktop-shell.md#6-人工核对清单每个窗口)），亮暗色均检查；
  - 设置键契约测试（[11 N3](./11-native-bridge.md#3-不变量)）通过；
  - 在设置窗口修改快捷键后，新快捷键立即生效。
- **估算**：3–4 天

### M2 — 首次启动引导

- **退出标准**：全新安装（删除 `settings.json`）时引导窗口出现，权限授予流程与之前一致；已完成引导的用户不再出现。
- **估算**：0.5–1 天

### M3 — 历史库（主窗口）

- **退出标准**：浏览、文字搜索、建立索引、删除、拼合截图均与之前一致；500 张截图时滚动流畅（使用 `@ddu/ui` 的 `virtual-masonry`）。
- **估算**：2–3 天

### M4 — 智能截图遮罩

- **退出标准**：区域、窗口、截图识字三种模式在多显示器上可用；遮罩出现时间不慢于迁移前（打包后实测，偏差 ≤ 50 ms）。
- **估算**：1.5–2 天

### M5 — 预览浮窗与编辑器

体量最大、风险最高的窗口：fabric.js 编辑器（约 860 行）、OCR 面板与浮窗位于同一个窗口，必须整体迁移。

- **退出标准**：浮窗的复制、编辑、提取文字，以及编辑器的全部工具、撤销/重做、像素化、OCR 面板与选区识别均与之前一致；编辑后的导出图片与迁移前逐像素比对一致（同一输入、同一操作序列）。
- **估算**：4–6 天

### M6 — 移除 Vue

- **退出标准**：`apps/desktop` 中无 `.vue` 文件；`vue`、`unocss`、`vue-tsc` 依赖已移除；TypeScript 回到目录版本 7，`vp check` 全绿。
- **估算**：0.5 天
